# R8 command override

This reference command documents that Linear tools are named like
`mcp__plugin_workflows_linear-server__get_issue`. It only explains the naming
convention — it invokes nothing, so the non-silent override downgrades R8 to advisory
on the command surface exactly as it does on the skill surface.
