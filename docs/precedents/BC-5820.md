## <a id="BC-5820-task-2"></a>Task 2 — BC-2717 task-1 fix-pass regression check reaffirmed at 8/10 (lighter-weight 2nd surface)

**Decision:** Fix-pass regression check on ≥5-edit fix passes is load-bearing — but lighter passes (5 small docs polish edits) successfully demonstrate the negative case (no regressions found).

**Confidence:** 8/10
**Category:** architecture
**Tags:** architecture, fix-pass, regression-check, lighter-pass, negative-evidence

**Why:**

- BC-2717 task-1 (1st surface, 2026-04-27 same day) registered the precedent at architecture-8/10 after a 13-fix pass introduced 2 real regressions caught only by a 2nd-pass review. Strong positive evidence.
- BC-5820 (2nd surface) had a 5-edit fix pass (1 P1 + 2 P2 + 8 P3 — 11 findings collapsed into 5 edits via bundling). Per the precedent's own prescription ("≥5-fix passes"), I ran a focused re-verification: read-back of all changed prose, cross-checks on link path (`docs/precedents/BC-5789.md`) and §3.5 cross-reference accuracy. Found **0 regressions.**
- This is **negative evidence** for the precedent — useful calibration. The discipline didn't catch anything *because* nothing broke. That doesn't disprove the precedent; it confirms the cost is low when results are clean.

**How to apply:**

- After any fix pass with ≥5 edits, run a focused re-verification before declaring done:
  - Read-back of changed prose (not just diffs — prose for coherence)
  - Cross-check links and cross-references for resolution
  - Sanity-check internal consistency between bundled fixes (e.g., if fix #N updates wording at line A, does fix #M's reference to line A still make sense?)
- For docs-only changes with no test/build harness, a focused human read-back substitutes for the BC-2717 prescription's "re-run review."
- Cost: ~1-2 minutes. Cheap insurance for a load-bearing fix pass.

**Calibration evidence:**

- BC-2717 (heavy pass, 13 fixes): 2 regressions caught
- BC-5820 (light pass, 5 fixes): 0 regressions caught
- Hypothesis: regression rate scales with fix-pass complexity AND inter-fix coupling. BC-2717's fixes were spread across 4 files with cross-citation interactions; BC-5820's fixes were all in one ADR section + a 3-line back-pointer, with each fix textually local. Future calibration:
  - **High-complexity fix pass** (≥10 edits, or ≥3 files, or any cross-file mirror updates) → run full Step 4 review-agent re-pass per BC-2717's prescription.
  - **Light fix pass** (<10 edits, single section, no mirror updates) → focused human read-back is sufficient.

**Promotion:**

- BC-2717 task-1 stays at architecture-8. BC-5820 task-2 doesn't promote it — same-day 1st surface (BC-2717 morning) and 2nd surface (BC-5820 afternoon) is too tight a window for promotion. But the bracket of evidence (heavy = 2 regressions, light = 0 regressions) refines the prescription: re-run scope should scale with pass complexity, not be uniform.
