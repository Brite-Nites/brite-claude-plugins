## task-3 — NEW PATTERN: sed-derivation incomplete coverage; simplify pass catches what mechanical swap misses

<a id="BC-6961-task-3"></a>

**Decision:** When mechanically deriving N near-identical files from a template via `sed`, certain string patterns silently escape the swap script and require post-derivation Edit + targeted scan: (a) strings split across line breaks in ASCII diagrams, (b) literal string values inside TypeScript code blocks not enumerated in the swap script, (c) array literals that need ROTATION per file (not simple substitution), (d) prose phrases with mixed canonical+specific phrasing. The simplify pass (3 parallel agents — reuse, quality, efficiency) caught 8 P1 bugs from this class with full agent consensus (all 3 agents independently flagged the same defects).

**Category:** pattern-choice

**Confidence:** 9/10

**Inputs:**
- BC-6961 derived 4 sibling files (plan-eng, plan-design, plan-qa, plan-docs) from plan-story.md via `sed` with 13 substitution patterns covering discipline-name swaps.
- Initial AC sweep (5 greps) passed cleanly — the sed script correctly handled marker pairs, reviewer-name references, `--refresh` flag, placeholder substring.
- Simplify pass (3 parallel general-purpose agents reading the 5 files independently) caught 8 P1 bugs the AC sweep missed:
  - `perspective: "story"` hardcoded in 4 sibling TypeScript code blocks (sed had no `perspective:` swap)
  - ASCII diagram references `plan-story-` split across 2 lines (`plan-story-\n   │  reviewer` — sed sees no contiguous `plan-story-reviewer`)
  - `sibling_summaries[]` arrays included file's own discipline + omitted Story (sed substitutes one-for-one; can't rotate)
  - `<story-child>.parentId` literal in list_issues example (sed had no `story-child` swap)
  - `<resolved-story-child-id>` literal in linear_writeback example
  - "active story children" in failure-table 1.2 (sed swap `s|discipline-story|discipline-eng|g` caught one occurrence but missed "active story")
- All 3 simplify agents independently flagged the same 6+ defects with conf 9-10 — high-consensus signal.

**Alternatives Considered:**
1. **Trust the AC sweep alone, ship as-is** — rejected. AC sweep checks for presence of markers/reviewer-refs/etc. but cannot detect that a file's CONTENT references the wrong discipline. The 5 greps pass even when 4 of 5 files have wrong perspective+diagrams.
2. **Make the sed script comprehensive enough to avoid the simplify-pass catch** — could be done by enumerating every split-line pattern and TypeScript literal. Rejected because: (a) high-cognitive-cost to enumerate exhaustively before writing the canonical file, (b) some patterns are genuinely per-file rotations (sibling_summaries) that sed cannot express cleanly, (c) the simplify-pass catch is structurally cheap and consensus-validated.
3. **Use the simplify-pass + AC-sweep two-layer mechanism (chosen)** — let sed do the 80% bulk swap; let simplify-pass catch the remaining 20% of content-level defects. Each layer plays to its strength.

**Outcome:**
- 8 P1 bugs caught in simplify pass (pre-review-loop); 4 P3 bugs caught in /workflows:review iter-1; 0 bugs at iter-2 (CONVERGED).
- 2-iter convergence on ~1290 LOC of new spec content (significantly faster than BC-6977 task-2's 4-iter convergence at 301 LOC). Hypothesis: simplify pass FRONT-LOADS the bug-catch, reducing the per-/workflows:review-iter find-count and accelerating convergence.
- Tests: all 6 ACs passed at both pre-simplify and post-simplify checkpoints; the simplify-pass fixes were content corrections invisible to AC greps.
- Approved by: in-flow review-loop iter-2 + independent post-PR reviewer round-2 both clean.

**Recipe for future sed-derived sibling files:**
1. Write canonical file (plan-X.md or equivalent).
2. Run sed with bulk discipline-swap patterns.
3. **MANDATORY: run simplify-pass with 3 parallel agents** before declaring derivation done. Even if ACs pass.
4. Cross-discipline reference scan: for each derived file, `grep "<discipline>"` (other discipline names) should return 0 hits in body content. Use this as a hard gate.
5. Then proceed to /workflows:review.

- [BC-6977 task-2](BC-6977.md#BC-6977-task-2) — 4-iter review-loop convergence at small LOC; this session's 2-iter convergence is a data point that front-loaded simplify-pass reduces /workflows:review iter-count.
