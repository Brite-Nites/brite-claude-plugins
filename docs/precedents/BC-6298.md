### Alternatives Considered

1. **Plan-gate question with both options + concrete examples** *(chosen)* — first attempt used engineering jargon ("§ Known gotchas," "BC-6306 propagation pattern") and confused the user ("I am confused"). Rephrase #2 used plain language with concrete file/diff examples for each option. User chose option 1 (mirror BC-6306). 3. **Silent precedent-application without asking** — rejected. Issue scope was narrower than the precedent; expanding without surfacing the gap would over-reach beyond issue authorization. Precedents inform, don't override.
