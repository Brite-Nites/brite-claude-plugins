# BC-2693: Add handbook (Context7) as universal SoR for context-skills

**Date:** 2026-03-31
**Category:** architecture
**Confidence:** 8/10

## Decision

Established the Brite Handbook (Context7) as a Tier 1 universal SoR for all context-skills, with domain-specific MCP tools as Tier 2. Context-skills query handbook first (always available), then domain MCP (if configured).

## Context

Context-skills previously only queried domain-specific MCP tools (HubSpot, GitHub, etc.) for enrichment. The handbook — already indexed on Context7 with 659 files — contains company-wide knowledge (brand, ICP, coding standards) relevant to every domain but wasn't part of the SoR pattern.

## Alternatives Considered

1. **Handbook as optional enrichment** — each skill decides independently whether to query handbook. Rejected: inconsistent behavior across domains, no standard pattern.
2. **Handbook merged into interview data** — bake handbook content into project-start. Rejected: handbook updates wouldn't propagate to existing context docs.
3. **Handbook as Tier 1 universal SoR (chosen)** — standard two-tier pattern with handbook always queried first. Consistent, resilient (5 fallback tiers), and handbook updates are live via Context7.

## Outcome

Updated BC-1966 spec and domain-plugin template. 5 fallback tiers: Full → Partial → Handbook-only → Domain SoR only → Interview-only. Handbook query pattern documented with recommended topics per domain.

**Precedent Referenced:** Context-Skill Standard (BC-1966)
